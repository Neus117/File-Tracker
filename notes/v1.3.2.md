# File Tracker v1.3.2

**取消置顶时，画面不再大幅跳动。**

## 修复

- **取消置顶不再把整块置顶项带出屏幕。** v1.3.1 让置顶跟焦之后，
  取消置顶会把视角**一路跟随那条记录**回到它的字母序原位 ——
  结果是置顶那一整块滚出视野，看起来像"大幅变动"。
  现在取消置顶**视角完全不动**（与 v1.3.0 的手感一致）。
- 置顶跟焦保持不变。

## 说明

- 根因是"保持视角"只有**一种口径**：跟路径。而两个动作需要的口径不同 ——
  置顶要把视角带到那条记录（**路径口径**），
  取消置顶要让视角原地不动（**行号口径**）。
  现在两套口径并存，各自声明。
- **不能"什么都不做"**：列表重建本身就会把滚动位置清零，
  不显式设回去等于跳回最顶端，比原来更糟。
- 除这一处外，功能与 v1.3.1 完全相同。

---

**English**

- **Unpinning no longer drags the pinned block off screen.** After v1.3.1 made
  pinning follow the row, unpinning followed that same row back to its
  alphabetical slot — which pushed the whole pinned group out of view and
  looked like a large jump. Unpinning now holds the viewport completely still
  (matching the v1.3.0 feel).
- Pin-follows-row is unchanged.
- The cause was that "preserve the viewport" had only one mode (follow the
  path), while the two actions need different ones: pinning follows the row,
  unpinning holds the scroll offset. Both modes now exist and are declared
  per action.
- Otherwise identical to v1.3.1.
