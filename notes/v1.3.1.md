# File Tracker v1.3.1

**置顶之后，视线跟着条目走。**

## 修复

- **置顶后视角不再留在原地。** 上一版引入"聚焦保持"之后，置顶一条记录
  会让它跳到最顶端，而视线**留在原处** —— 用户会疑惑
  "我置顶的条目呢？怎么不见了？"，得往上翻才看得见。
  现在置顶时**焦点跟随**，直接落到被置顶的那条（最顶端）。
- **取消置顶的逻辑保持不变** —— 那时条目还在附近，保持视线才是对的。

## 说明

- 根因是 `on_pin` 与 `on_unpin` **共用同一段"保持视角"的代码**，
  而两个动作的语义相反：置顶把条目挪到最顶端，取消置顶让它回到附近。
  现在置顶会额外声明一个一次性的"重建后聚焦到这条"意图。
- 除这一处外，功能与 v1.3.0 完全相同。

---

**English**

- **Pinning now brings the row into view.** v1.3.0 introduced "keep the
  viewport steady", which meant that pinning a record moved it to the very top
  while your view stayed where it was — you had to scroll up to confirm it
  worked. Pinning now follows the record to the top.
- **Unpinning is unchanged** — the row stays nearby, so holding the view is
  still the right behaviour.
- The cause was that pin and unpin shared the same "preserve the viewport"
  path, although the two actions move the row in opposite directions.
- Otherwise identical to v1.3.0.
