# File Tracker v1.4.2

**回车更快、开着用一天也不变慢；深色主题漏掉的三处补上了；弹窗的警告标志改成自绘。**

> 注：`v1.4.1` 的产物缺失在仓库里（构建于另一台检出），这一版把 1.4.1 之后
> 的全部修复一并带上。

## 一、地址栏回车：296 → 70 毫秒

输入 `C:\Windows\System32\drivers\etc` 这类深路径回车时，树会沿路径逐级展开。
旧实现**每一级祖先都把全部子项建出来，包括文件** —— `System32` 一个目录就有
4907 个（其中 4708 个是文件），而它们只是为了把下面的 `etc` 显示出来。

| 指标 | 改前 | 改后 |
|---|---|---|
| 回车（同步耗时） | 296 ms | **70 ms** |
| 树节点增量 | +5789 | **+614** |
| 关闭（699 节点 vs 5874） | 367 ms | **85 ms** |

现在：条目超过 300 的目录在"沿路径展开"时**只建子文件夹**，你点开它时文件才补上
（只追加、不重建树干，所以不会有节点失效）。

## 二、开着用一整天不再变慢

旧实现"打开过的目录永远保持展开、节点从不回收"。实测成本曲线是**超线性**的：

| 树里节点数 | 一次导航 | 关闭 |
|---|---|---|
| 6 295 | 86 ms | 352 ms |
| 45 746 | 308 ms | **10 941 ms** |

三条措施：

1. **导航时收起上一次那条链**（只保留当前路径展开；你手动点开的分支不动）；
2. **节点超过 4000 就整体重建**，只保留当前路径（手动展开那条线是 12000，避免
   "刚点开就被拆掉"）；
3. **`WinSxS` 这类两万项的目录改分页**：一次显示 800 个 + 末尾一行
   「还有 N 项未显示，收起再展开可继续」，每页约 0.1 秒（全量要 2.7 秒）。

顺带：用「打开」按钮打开导航窗格里的选中项时，也会收起旧路径（与地址栏回车一致）。

## 三、深色主题的三处漏洞

| 症状 | 真因 | 修法 |
|---|---|---|
| 深色主题下右键菜单是白的 | 进程级深色模式按**系统**主题决定 | 改按**程序的主题偏好** |
| 浅色主题下右键菜单是深的 | 浅色误传 `Default`（= 跟随系统） | 改传 **ForceLight** |
| 运行中切主题后菜单不跟着变 | 浅→深需要刷新菜单主题 | 切换后补 `FlushMenuThemes` |

实测（抓整块菜单取众数色）：深色启动 `(44,44,44)`、浅色启动 `(249,249,249)`、
深→浅 `(249,249,249)`、**浅→深 `(44,44,44)`**。

## 四、弹窗警告标志改成自绘

`⚠️` 是字体字形 —— **大小由字体决定，做不到"比正文更大"**。现在按
`Icons-Drawing.md` 的 `warning` 徽标用几何图元画：等边三角 + 线框 + 感叹号，
边长 = 正文行高 × 1.8，紧贴正文左侧并与文字**作为一组居中**。

## 五、测试与门禁

| 项 | 结果 |
|---|---|
| 单元测试 | **220** 条通过 |
| 界面检查（真实窗口） | **255** 项通过 |
| 静态门禁 | 接线 / 对话框 / 重复方法 / 审计 50 条 / README 双语 / `.ps1` BOM 全通过 |

新增探针：`probe_pathbar_populate.py`（逐次建节点的调用点与耗时）、
`probe_tree_accumulate.py`（长会话累积）、`probe_tree_inflate.py`（节点数→耗时曲线）、
`probe_menu_dark.py`（系统绘制控件的真实颜色）。

## 已知限制

- 直接导航到一个**条目极多**的目录（如 `C:\Windows\WinSxS`）时，它自己仍会全量展开；
  想逐页看就点它的展开箭头。
- 记录条数很多时，「打开」一条记录仍会重排列表（v1.3.3 已优化约一半）；
  根因是 `wx.ListCtrl` 不支持虚拟列表下的逐项底色，详见 README「已知限制」。

**English**

- **Faster Enter in the address bar**: 296 → 70 ms for a deep path, and the tree
  grows by 614 nodes instead of 5789.
- **No more slow-down after a long session**: navigating collapses the previous
  path, the tree is rebuilt past 4000 nodes, and huge folders (`WinSxS`, 19727
  entries) are paged 800 at a time.
- **Three dark-theme holes closed**: the process-level dark mode now follows the
  app's theme (not the system's), the light setting uses ForceLight instead of
  "follow the system", and switching the theme at runtime flushes the menu theme.
- **The dialog warning badge is drawn**: an equilateral outlined triangle with an
  exclamation mark, 1.8× the body line height (the `⚠️` glyph could not grow).
- Automated tests: **220 unit tests + 255 GUI checks**.
