# File Tracker v1.2.2

## 新增

- **中英文双语界面**：按 Windows 显示语言自动选择，也可在设置里指定并记住。
  切换即时生效，无需重启。
- **设置窗口**（底部右侧、顶置按钮左边），目前用于切换界面语言。
- **可执行文件带版本信息**：文件说明、文件版本、产品名称、产品版本、版权。
  此前「属性 → 详细信息」那一页几乎是空的。

## 说明

- 版本资源里的产品版本是干净的 `1.2.2`；构建提交哈希仍只在
  `--version` 的输出里（`File Tracker 1.2.2+<短哈希>`）。
- 界面语言跟随系统；版本资源固定英文——那一格只能填一种语言，
  而打开文件属性的人未必读中文。
