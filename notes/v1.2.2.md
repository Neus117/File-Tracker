# File Tracker v1.2.2

## 新增

- **中英文双语界面**。语言按 Windows 的显示语言自动选择
  （`GetUserDefaultUILanguage`），也可以在设置里手动指定并记住。
  语言名用自己的语言写——中文界面里找英文选项，看到的仍是 "English"。

- **设置窗口**（底部右侧、顶置按钮左边）。目前可切换界面语言，
  **点确定立即生效**，不需要重启。

- **可执行文件带版本信息**（「属性 → 详细信息」）：
  文件说明、文件版本、产品名称、产品版本、版权。
  此前那一页几乎是空的。

## 说明

- 版本资源里的「产品版本」是干净的 `1.2.2`；
  构建提交哈希仍然只在 `--version` 的输出里
  （`File Tracker 1.2.2+<短哈希>`）——对报障有用，但不该出现在属性页。
- 界面语言跟随系统，版本资源固定英文：那一格只能填一种语言，
  而打开文件属性的人未必读中文。
