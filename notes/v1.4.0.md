# File Tracker v1.4.0

**这一版改动比较多：视觉全面调优、修掉三处缺陷、时间与日期合并成一列。**

## 视觉

**记录表改成三列**：访问路径 / 频次 / 访问时间。

**时间与日期合并成一列** —— 原来是两列，现在一行读完，列头点一下就能按它排序。

其余是在细节上逐项对齐：

- 列与列之间加了分隔线（顶置行、普通行、表头各用一档灰度，深色主题单独一套）
- 表头带排序箭头 ▲/▼，当前排序列一眼可见
- **设置窗口全部换成自绘图标按钮**：显示器 / 太阳 / 月亮 / 文件夹 / 柱状 / 时钟 /
  ↑ / ↓ 共 8 个图形，每个都带中文或英文的悬停提示
- 行内边距、列宽、按钮尺寸、浅深两套主题的对比度，都按像素量过一遍

**主题有三档**：跟随系统 / 浅色 / 深色。切换即时生效，不用重启。

## 修复

- **多选之后清空，程序会卡死十几秒到几分钟。** 6000 行实测从 **166 秒**降到
  **0.2 秒**。根因是取消选中时逐行触发了"重画全表"，等于约 3600 万次原生调用。
- **双击一条记录会抛 `AttributeError`。** `event.Veto()` 只存在于列表事件上，
  而同一个处理函数同时挂了鼠标双击事件。
- **切换界面语言时，窗口标题和图标悬停提示没跟着变**（其余文字都变了）。
  现在整个设置窗口都是一次到位的，不用点「确定」。

## 说明

- **界面与磁盘格式与 v1.3.3 兼容**，直接覆盖 exe 即可，不需要动数据库。
- 体积 **12.70 MB**（v1.3.3 是 12.99 MB）。
- 自动化测试从 197 条增加到 **200 条单元测试 + 214 项界面检查**。

**English**

**A fairly large release: a visual pass over the whole UI, three defects fixed,
and date + time merged into a single column.**

**Visual**

The record table now has **three columns**: path / count / last visit.

**Date and time share one column** — they used to be separate; now one line tells
the whole story, and clicking that header sorts by it.

The rest is alignment work, item by item:

- Separators between columns (one grey level each for pinned rows, normal rows and
  the header, with a separate set for the dark theme)
- The header shows a ▲/▼ sort arrow, so the active sort column is obvious
- **The settings dialog is now built from self-drawn icon buttons** — eight glyphs
  (monitor / sun / moon / folder / bars / clock / ↑ / ↓), each with its own
  Chinese or English tooltip
- Row padding, column widths, button sizes and the contrast of both themes were
  all measured rather than eyeballed

**There are three theme choices**: follow the system / light / dark. Switching
takes effect immediately.

**Fixed**

- **Clearing a multi-selection could freeze the app for anything from seconds to
  minutes.** On 6000 rows it went from **166 s** to **0.2 s**. The cause was a
  per-row "repaint the whole table" cascade — roughly 36 million native calls.
- **Double-clicking a record raised `AttributeError`.** `event.Veto()` only exists
  on list events, and the same handler was also bound to a mouse double-click.
- **Switching the UI language left two things stale**: the window title and the
  icon tooltips (every other string did update). The whole settings dialog now
  updates in one step, without pressing OK first.

**Notes**

- **The UI and the on-disk format are compatible with v1.3.3** — just replace the
  exe, no database changes needed.
- Download size is **12.70 MB** (v1.3.3 was 12.99 MB).
- Automated tests grew from 197 to **200 unit tests + 214 GUI checks**.
