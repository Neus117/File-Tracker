# File Tracker v1.2.0

**第一个现代化版本：界面重做、交互修正、工程补齐。**

## 新增

- **左侧地址栏**：粘贴或输入路径后回车，直接展开到该位置，并记录一次访问
  （与双击列表项等同，计入频次）。`Ctrl+L` 聚焦；
  也接受带引号的「复制为路径」，以及正斜杠。
- **深色 / 浅色主题跟随系统**，配色与字号从系统读取。
- **警告 / 确认弹窗全部自绘。** 系统对话框在深色主题下永远是浅色面板，
  没有受支持的换肤接口。
- 初始窗口增大 15%（1280×720 → 1472×828），并按显示器工作区自动夹取。

## 界面

- **自绘表头**：原生表头在深色主题下不接受任何设色。自绘后与数据行
  共用同一处列分隔线计算，保证不错位、粗细一致。
- 列分隔线为 **1 物理像素**（不随 DPI 放大），只画竖线、不画横线。
- 置顶行保留黄色强调（`#FFFFB7`）—— 它与「选中行」是两件不同的事。
- 鼠标悬停时整行显示次级高亮，单击后显示高亮，两档颜色分明、无延迟。
- 卡片式分层，间距统一到 4 像素网格。
- 「频次」列数字居中。
- 底部按钮：「打开」在最左、「清空」居中。

## 修复

- **双击失效路径会直接删除，改为先弹窗询问。**
  删除不可逆，选择权应当留给用户。
- **退出时整表重写数据库。** 旧实现先清空、再从界面把所有行插回，
  于是任何"只改数据库不改界面"的操作都会被下一次退出抹掉。
  现在数据库本身就是真相来源。
- **配置保存会互相覆盖。** 存了浏览目录再存滚动位置，会把目录丢掉。
- 配置里存着已失效的盘符时，目录树会得到一棵空树；现在回退到 `C:\`。
- **从源码运行时，图标与固定按钮图片必然加载失败。**
  v1.1 重写时丢掉了资源路径解析，代码去找一个不存在的目录，兜底又是
  开发机上的路径。现已恢复，并让加载失败可见（写日志 + 可读的降级表现）。
- **两个方法各被定义了两次**（`set_icon`、`load_last_directory`）——
  Python 静默用后一个，改前一个不会有任何效果。
- **导航窗格的两处边框问题**：浅色下的"双重顶栏"、深色下的白框线。
- **列表只有文字部分能点中行** —— 整行选中的样式位被一次误操作清掉了。
- 列表文字改为纯黑（浅色）/ 纯白（深色），取消原来的灰色。

## 说明

- 移除「切换排序」按钮 —— 点列头即可排序。
- 本版补上了打包配置与 CI。此前仓库里没有任何打包配置，
  v1.1.0 那个 exe 怎么打出来的只存在于作者记忆里。
- 产物从此能自报构建提交：`--version` 输出 `File Tracker 1.2.0+<短哈希>`。
- 源码拆成不依赖 wx 的核心层与界面层，测试从"零覆盖且会开窗"
  改为 122 条不依赖 GUI 的测试。

**English**

- **Address bar**: paste a path, press Enter, and it jumps there and records a
  visit (`Ctrl+L` to focus).
- **Light / dark theme follows the system**, and custom-drawn header and dialogs
  replace the native ones, which ignore colour under a dark theme.
- **Double-clicking a stale path now asks before deleting**, instead of
  deleting and then telling you.
- **Settings no longer overwrite each other**, and the database is the source of
  truth rather than being rebuilt from the list on exit.
- Fixed: icons failing to load when run from source, two methods defined twice,
  the pane's double title bar and white border, and rows only responding to
  clicks on the text.
- Added the packaging config, CI, and 122 GUI-free tests.
