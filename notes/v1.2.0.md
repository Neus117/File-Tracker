# File Tracker v1.2.0

## 新增

### 左侧地址栏

粘贴或输入文件夹路径后回车，直接展开目录树到该位置，并记录一次访问
（与双击列表项完全等同，计入频次）。支持 `Ctrl+L` 聚焦。
也接受"复制为路径"带引号的形式与正斜杠。

### 界面

- **深色 / 浅色主题跟随系统**，配色与字号从系统读取。
- **自绘表头**：原生 `SysHeader32` 在深色主题下不采纳任何设色，
  改为自绘，并让表头与数据行的列分隔线共用同一处几何计算
  （`ColumnHeader.separator_positions()`），保证不错位、粗细一致。
- **列分隔线**：1 **物理**像素（不随 DPI 放大），只画竖线、不画横线。
- **置顶行**保留黄色强调（`#FFFFB7`），与"选中行"是两件不同的事。
- **预选跟随**：鼠标悬停时整行显示次级高亮，单击后显示高亮，
  两档颜色分明；悬停无延迟。
- **卡片式分层**与统一到 4 像素网格的间距。
- **警告 / 确认弹窗全部自绘**：系统对话框在深色主题下永远是浅色面板。
  尺寸与间距按固定公式手算（不 `Fit()`），正文逐行居中。
  标题栏带程序图标，`⚠️` 放在正文开头。
- **"频次"列数字居中。**
- 初始窗口增大 15%：1280×720 → 1472×828，并按显示器工作区自动夹取。

### 交互

- **失效路径改为先询问**：双击 / 打开一条失效路径时，弹窗征求是否删除，
  而不是直接删除后再通知"已删除"。删除不可逆，选择权应当留给用户。
- 移除「切换排序」按钮（列头点击即可排序）。
- 「打开」在底部最左、「清空」在底部居中。

## 修复

### 数据与配置

- **退出时整表重写数据库**：旧实现先 `DELETE FROM paths` 再从界面把所有行插回，
  任何只改数据库不改界面的操作都会被下一次退出抹掉。现在数据库本身就是真相来源。
- **配置保存会互相覆盖**：`save_last_directory` 与 `save_scroll_position` 各自
  整份重写文件，只有后者先读，所以"先存目录再存滚动位置"会把目录丢掉。
- 配置里存着一个已失效的盘符时，目录树会得到一棵空树；现在回退到 `C:\`。

### 界面

- **从源码运行时图标与固定按钮图片必然加载失败。** v1.1 重写时丢掉了
  `resource_path()`，代码去找 `<repo>\src\images\`（不存在），
  兜底又是开发机上的 `D:\Work\...`（也不存在）。现已从 v1.0.3 恢复，
  并让加载失败可见（写日志 + 可读的降级表现，不再是空白的按钮）。
- **`set_icon` 与 `load_last_directory` 各被定义了两次**，Python 静默用后一个，
  前一个成了死代码，而两份的失败处理还不一样。已各留一份。
- **导航窗格的白色双重顶栏**：真实原因是 `GenericDirCtrl` 自带的
  2 像素**非客户区**边框（`SetBackgroundColour` 对它无效），
  改用 `wx.BORDER_NONE` 后归零。
- **深色主题下导航窗格四周的白框线**：`GenericDirCtrl` 容器自身的底色
  与内层树是两回事，容器也要设色。
- **只有文字能点中行**：`LVS_EX_FULLROWSELECT` 被一次
  `clear_extended_style(handle, LVS_EX_GRIDLINES)` 以 `lparam=0` 抹掉了。
  现在读—改—写整个 32 位掩码。
- **按钮右边缘"裁断感"**：`DrawRoundedRectangle` 的 1 像素描边以路径为中心
  向两侧各扩半像素，外半像素落在客户区外被裁。规则是
  **矩形取 `(W-1) × (H-1)`、一点都不平移**——平移会让边界落在像素中间，
  抗锯齿把覆盖分摊到相邻两列，看上去就是"边缘淡了一层"。
- **路径记录文字改为纯黑（浅色）/ 纯白（深色）**，取消原来的灰色。

### 工程

- **新增打包配置**（`File-Tracker.spec`）与构建脚本（`build.ps1`）。
  仓库此前没有任何打包配置，v1.1.0 那个 exe 怎么打出来的只存在于作者记忆里。
- **新增 CI**（`.github/workflows/build.yml`）。
- **产物能自报"是哪个提交构建的"**：`--version` 输出
  `File Tracker 1.2.0+<短哈希>`。
- 源码拆成不依赖 wx 的核心层与界面层，`tests/` 从"零覆盖且会开窗"
  改为 122 条不依赖 GUI 的测试。
- **新增 `tools/verify_gui.py`**：116 项基于几何与属性的运行时断言
  （不依赖像素取样——本环境的窗口抓图已被证明不可靠）。
- **新增 `tools/check_wiring.py`**：接线检查，扫出"定义了但没人调用"的方法、
  "没人读取"的常量、硬编码开发机路径、未使用的配置键；
  并自带反向检查证明它**确实会拦**。
- 移除运行时依赖 `pywin32`（源码从未使用它）。

## 已知限制

- 界面美化目前依据的是 Roboc 项目的视觉规范（系统取色、字体层级、强调色语义）。
  用户自己的美学规范尚未提供，拿到后会再调一轮配色与绘制。
- 悬停预选与选中高亮由本项目自绘，而非依赖原生热跟踪——
  原生那套的绘制随主题而变（实测深色有、浅色没有），第三方改不了。
