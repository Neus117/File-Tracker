# File Tracker v1.2.5

**修复版：新顶置的条目现在排在最前面。**

## 修复

- **顶置顺序不符合直觉。** 上一版里，新顶置的条目会排在所有已置顶条目的
  **最后**；现在排**最前**。

## 说明

- **这是 v1.2.4 引入的回归。** 当时的理由是"让内存顺序与数据库顺序一致，
  从而不需要数据迁移" —— 重启漂移确实治好了，代价是弄坏了看得见的行为。
- 根子是一直没有"顶置顺序"这个东西，只有"首次访问的先后"。
  现在数据库多了一列**真正记录顶置顺序**，于是
  **"新顶置排最前"与"重启后顺序不变"可以同时成立**。
- **升级不会重排你现有的顶置列表** —— 老数据按你当前看到的顺序回填，
  升级前后看到的顺序完全一样。
- 除顶置顺序外，功能与 v1.2.4 完全相同。

---

**English**

- **Pin order fixed.** In v1.2.4 a newly pinned entry went to the *bottom* of the
  pinned group; it now goes to the *top*.
- This was a regression from v1.2.4. The fix stores the pin order in the
  database, so "newest first" and "order survives a restart" both hold.
- **Upgrading does not reorder your existing pinned list.**
- Otherwise identical to v1.2.4.
