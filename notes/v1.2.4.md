# File Tracker v1.2.4

## 修复

- **「打开」按钮现在跟着你最后一次选中的那一处。**
  此前它只看左侧导航窗格，在右边记录窗格里选哪一条都没用。
  在导航窗格里选中 → 打开那个目录；在记录窗格里选中 → 打开那条记录。
  两处为空时互相回退。
- **失效路径的提示只给一个按钮。** 此前它有「好 / 否(N)」两个按钮，
  而两个都只是关掉弹窗。那是一条"已经做完了"的告知，不是问题。

## 说明

- 一次只打开一处。此前导航窗格多选时会一次弹出多个资源管理器窗口。
- 新增对话框调用点检查（`tools/check_dialogs.py`）并纳入构建：
  「给了两个按钮却没读返回值」这类缺陷以后在构建时就会被拦下。
