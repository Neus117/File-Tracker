# File Tracker v1.2.4

**一次大扫除：修掉一批"静默做错事"的缺陷，产物小了 17%。**

## 修复

### 交互

- **「打开」跟着你最后一次选中的那一处。**
  此前它只看左侧导航窗格，在右边记录窗格里选哪一条都没用。
  在导航窗格选中 → 打开那个目录；在记录窗格选中 → 打开那条记录；
  两处为空时互相回退。
  - 这条修过一次没修对：真正的原因不在时序，而在**事件来源** ——
    目录树被程序改动选中时也会发事件，把用户的选择顶掉了。
    现在只认"只可能由用户操作产生"的事件（焦点、方向键）。
  - 点**已经选中**的那一行也算（此前那种情况不会触发选中事件）。
  - 一次只打开一处 —— 此前导航窗格多选时会一次弹出多个资源管理器窗口。
- **失效路径的提示只给一个按钮。** 此前它是「好 / 否(N)」两个按钮，
  而两个都只是关掉弹窗。那是一条"已经做完了"的告知，不是问题。
- **路径栏提示语跟随语言。** 它原是类属性，在 import 时就被求值并冻结，
  于是切换语言后提示语不变（要重选一次语言才生效）。

### 数据安全

- **配置写入改为原子操作。** 原来是原地截断重写，写到一半失败就留下半截
  文件，下次读到就**所有偏好丢失** —— 而写入很频繁（每点一次表头就存一次）。
  现在写临时文件再替换，并先落盘。
- **损坏的配置会留一份 `.corrupt`**，不再静默重置 —— 手改配置是明确支持的用法。
- **导入失败会整体回滚。** 此前中途失败会把删除语句留在未提交的事务里，
  此后任何一次提交都让它永久生效 —— **"导入失败"的后果是整张表消失**。
- **零行写入不再被当成成功。** 导航窗格停在失效路径上时，确认删除会报告
  "已从记录中删除"，而实际什么都没删。顶置同理。
- **顶置顺序跨重启保持。** 此前新顶置的排在最后，但重启后按数据库 `id`
  重建，顺序会悄悄变化。
- **复制路径失败会告知，且剪贴板一定会关闭。** 此前失败是静默的，
  而中途抛异常会让剪贴板被本程序占住直到退出。
- **退出时会取消挂起的回调。** 原来有十几处延迟回调排队等着执行，
  而窗口正在被销毁 —— 回调跑到就会碰已释放的对象。
- **日志不再被鼠标移动刷屏，且有了大小上限**（超过 256 KB 只留最近一半）。

### 界面

- **列表高亮与边框不再谎报成功。** 此前"读样式失败"与"本来就没有边框"
  都返回 0，于是一律当成成功 —— 调用方以为边框归自己画，结果两边都没画。

### 性能

- **每次打开记录的重建次数减半** —— 原来整个列表被清空重建两遍
  （两个方法做的是同一件事）。
- **列宽量测加采样上限**（200 行），从 O(N) 变成 O(1)；
  并修掉它的重入 —— 一次操作里真正做事 **5 次 → 1 次**。

## 体积

**16.12 MB → 13.3 MB（−17.5%）**，而且是在**功能变多**的前提下：

- 不再把文档用的展示图打进 exe（程序运行时不读，358 KB）
- 排除只有标准库内部才用到的 `tarfile` / `hashlib` / `email`
  —— 它们会连带把 2.11 MB 的 `libcrypto-3-x64.dll` 拉进产物

## 说明

- **`--version` 在没有控制台时不再卡死。** windowed 产物没有 stdout，
  于是它转去一条需要界面环境才能用的记日志路径，那条路会停在
  一个等人点击的断言框上 —— 命令行场景没有人点，进程就停在那里。
  现在这条路完全不依赖界面，且提示框会自动关闭。
- **清理**：删掉重复定义的方法、无人调用的方法，以及一批 PyQt5 时代的
  遗留文件；`.gitignore` 去掉了几条过于宽泛的规则（不带锚点的目录名会
  静默忽略任何一层的同名目录）。
- **新增三个静态检查器**，都带阳性对照、都纳入构建与 CI：
  对话框调用点、重复方法定义、审计条目清账。

**English**

- **"Open" follows the last place you selected.** It used to look only at the
  left pane; selecting a row on the right made no difference.
- **A stale path is reported with one button.** It used to offer "OK / No",
  where both just closed the dialog.
- **Silent-failure fixes:** a half-written settings file no longer loses all
  preferences (writes are atomic, and a corrupt file is kept as `.corrupt`); a
  failed import rolls back instead of possibly wiping the table; deleting a
  stale path no longer reports success; the clipboard is always released; and
  pin order survives a restart.
- **Faster**: opening a record went from two full list rebuilds to one, and the
  column-width pass from five runs to one.
- **Size 16.12 MB → 13.3 MB (−17.5%)** while adding features.
- **`--version` no longer hangs without a console.**
