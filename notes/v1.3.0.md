# File Tracker v1.3.0

**体验版：更舒服的行距与图标，更快的导航，双击后视线不跑，设置所见即所得。**

## 大幅性能提升

- **导航窗格展开大目录快了约 8 倍。** `C:\Windows`（85 个子目录）
  从 **241 ms** 降到 **35 ms**；`C:\Windows\System32`（199 个）从
  **275 ms** 降到 **36 ms**。
  两处原因：批量插入节点时没有冻结重绘（每个节点都重排一次），
  以及列目录时每个条目要发三次系统调用。
- **修掉一处平方级复杂度。** 反查"节点对应哪个路径"原本是**全树搜索**，
  而它会被遍历器**对每个节点**调用一次 —— 记录一多，回车就卡死
  （表现为"程序未响应"）。现在改为沿父链上溯，是 O(深度)。

## 大量视觉调优

- **行距按比例统一。** 记录窗格与导航窗格共用同一个 `row_ratio`（1.8），
  两个窗格的行距比例**完全一致**，排版更透气。
- **导航窗格换成自绘目录树，图标放大一倍**（16 → 32 px）。
  此前"磁盘、文件夹的标识太小，看着很费劲"—— 根因是行高调大后
  图标没跟着变（图标/行高只有 0.32，资源管理器约 0.73），
  而系统控件**不提供任何更换图标尺寸的接口**，只能换控件。
- **图标观感优化**：设置窗口的主题按钮改为**自绘图形**
  （显示器 / 太阳 / 月亮），不再依赖字体里有没有那个字形。
- **路径输入框的框线加深了一级**（浅色与深色主题各一级），更容易注意到。
- **行内竖线、选中高亮的细节**一并校正。

## 聚焦保持：双击之后视线不跑

- **位置不动。** 以前双击打开一条靠下的记录，列表重排后会**跳回最开头**。
  现在刷新前后**位置完全不动**（排序未变时一行都不滚）。
- **选中不丢。** 蓝色选中仍然停在刚打开的那一条上，
  不会跑到很远的另一条去。
- **看不到中间过程。** 刷新、滚动、再定位这一串动作被完整隐藏，
  用户只看到频次和时间变了。

## 设置更加完善（及时反馈）

- **所见即所得。** 主题、语言、排序方式、排序方向 —— 点一下**立刻生效**，
  不用等"确定"。
- **新增主题切换**（跟随系统 / 浅色 / 深色）。
- **点"确定"不再重复刷新。** 之前在预览已经生效的情况下，
  确定会**把每一项再应用一遍**，界面会抖一下。现在确定只负责保存。
  点"取消"仍然完整回退（会刷新一次，这是应该的）。
- **版面重排**：标题居左、按钮在右，类别之间留空行，确定/取消靠右下。

## 其它

- **体积 13.31 → 12.96 MB**（功能变多，反而更小）。
  本轮排掉了 PyInstaller 默认打进产物、而本项目从不使用的
  wx html 子模块（0.39 MB）。
- **新增 16 条健壮性边界用例**：超长路径（299 字符）、深路径（12 层）、
  目录在展开前被删掉、重复填充、无效输入、以及"重建抛异常后控件
  没有被永久冻结"。
- 单元测试 **192 条**、界面检查 **186 项**，全绿。

## 说明

- **升级不影响你已有的记录、顶置与排序偏好**，数据库结构未变。
- 导航窗格的行高与图标尺寸会**跟随你的 DPI 与系统字号**缩放。
- **空目录也会显示展开箭头** —— 有没有子目录只能等展开时才知道，
  这是与资源管理器同款的取舍。

**English**

- **Navigation is roughly 8× faster.** Expanding `C:\Windows` (85 subfolders)
  went from **241 ms** to **35 ms**; `C:\Windows\System32` (199) from 275 ms
  to 36 ms. Two causes: nodes were inserted without freezing redraws, and
  listing a directory cost three syscalls per entry.
- **A quadratic path lookup was removed** — it ran once *per node* and made
  the window hang on Enter once you had enough records.
- **Spacing is now ratio-driven**: both panes share one `row_ratio` (1.8), so
  their line spacing matches exactly.
- **The navigation tree is now custom-drawn with 2× icons** (16 → 32 px). The
  old system control offered no way to change icon size at all.
- **Theme buttons are drawn shapes** (monitor / sun / moon) instead of relying
  on font glyph coverage.
- **Path box borders are one step darker**, in both themes.
- **Focus is preserved.** Double-clicking a record no longer scrolls the list
  back to the top; the position stays put, the selection stays on the row you
  opened, and the whole refresh is hidden from view.
- **Settings are live.** Theme, language, sort column and direction apply the
  moment you click. A theme switcher was added. **OK no longer re-applies
  everything** (it used to make the window flicker); Cancel still reverts fully.
- **12.96 MB**, down from 13.31 MB — the unused wx html submodule is no longer
  bundled.
- **192 unit tests, 186 GUI checks**, all green.
- **Upgrading does not affect your records, pins or sort preferences.**
